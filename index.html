No. 001 / Close the fucking tabsA short rant. A shorter solution.

01 / The fucking point

You could’ve asked it
by now.

You opened a tab to find the best AI agent. Then a benchmark. Then a thread explaining why the benchmark is bullshit. Then a video of a man in a purple room telling you everything changed this morning.

It’s now lunchtime. The button is still off-center.

Ask the fucking thing to fix the button.

Give it the file. Tell it what’s wrong. Let it take a swing. You can reject the result. You can correct it. You can discover that doing it yourself was faster. All of those are more useful than becoming the world’s leading unpaid expert on model pricing.

Your backlog doesn’t give a shit
which model tops the leaderboard.

02 / The advanced workflow

Type a fucking sentence.

No sacred incantation. No “act as a world-class 10× principal wizard.” Describe the job like you’re asking a competent colleague who has absolutely none of the context in your head.

↙ Start here
>

Help me fix this bug. Expected: [what should happen]. Actual: [what happens]. Reproduce it, find the cause, and make the smallest fix. Run the relevant checks. Show me what changed and anything you couldn’t verify.

Fill in the blanks. Attach the context.

That’s a prompt. You are now qualified to close the prompt-engineering tutorial.

03 / Give it something to work with

It can’t read your
fucking mind.

You typed “it’s broken” into an empty chat and expected a diagnosis. Broken what, Sherlock? The build? The layout? Your relationship with deadlines?

−Vague request: make it better

+Useful request: The navigation overlaps the logo at 375px. Fix the mobile layout. Keep the desktop design. Check both sizes.

Tell it what you want, what it can use, what it must leave alone, and what “done” looks like. Files. Error messages. A screenshot with the actual problem in it. The boring details are the good prompt.

And if it can inspect your project, let it inspect your project. You don’t need to personally ferry every line of code between two windows like a clipboard with health insurance.

04 / Congratulations on your new hobby

You built a committee.
You needed a script.

A planner agent. A researcher agent. An architect agent. A critic agent to critique the architect agent. A supervisor to ask why nobody has written the fucking script.

Planner→Architect→Critic→No fucking script

You’ve recreated a middle-management department in your terminal. It has a token budget and no deliverables.

Start with one agent and one clear task. Add the elaborate setup when you can point at the problem it solves. Your AGENTS.md should not need its own onboarding program.

05 / The objection department

Yes, but—
oh my fucking god.

Pick the thing you were about to say.

“But which agent is the best?”+

Try the one you already have access to, on a real task you can judge. Did it help? Where did it fail? There’s your useful comparison.

You’re fixing a form, not choosing a bloodline. You can use a different one tomorrow.

“But it hallucinates.”+

Yes. It can invent an API with the confidence of a man explaining your own job to you. Ask for evidence. Open the sources. Run the code. Check the result.

“The agent said it works” is a sentence. A passing check is evidence. Learn the fucking difference.

“But I tried it once and it sucked.”+

Maybe it did. Give it a bounded task and enough context, then judge that result. If you’re still spending more time correcting it than it saves, do the task yourself.

You’re allowed to use a tool without defending it on the internet. Incredible new feature of being an adult.

“But I need to learn this myself.”+

Then ask for an explanation, a hint, or a review of your attempt. Tell it not to write the solution. Predict what the code does, then check your prediction.

Outsource the part you don’t need to practice. Keep the part you do. Your brain is still invited.

“But my code is private.”+

That’s a constraint. Use a tool and data policy you’re allowed to use, or don’t share the code. Work with a stripped-down example if that’s permitted.

“Just ask” is not a request to paste the company’s secrets into whatever has a shiny input box.

“But I need the perfect setup first.”+

Your agent has twelve integrations, six custom personas, and a color scheme called Midnight Productivity. You have not completed a task.

Give the default setup one actual job before you install a plugin to optimize the plugin that manages your plugins.

“But it keeps overengineering everything.”+

Tell it to make the smallest useful change, reuse what exists, and avoid new dependencies unless they’re needed. Then enforce that when you review.

If you asked for a doorbell and got an event-driven visitor orchestration platform, send it the fuck back.

“But I enjoy doing it by hand.”+

Then do it by hand. Seriously. Enjoying the work is a perfectly good reason.

This page is for the person avoiding a task while researching tools to do the task. If you’re happily doing the task, you have already beaten this website.

06 / Keep your brain switched on

Ask your agent.
Read the fucking diff.

“Accept all” is not a code review. It’s a surprise subscription to whatever happens next.

Look at what changed. Check that it solved the actual problem. Run the relevant tests. For research, follow the sources. For writing, read the words. For a spreadsheet, check the numbers.

Don’t hand it the keys to production because it said “Absolutely!” with convincing punctuation.

Delegate the work. Keep the judgment. The task is yours even when the typing isn’t.
